# next-to-do

这目录现在只保留两个稳定入口：
- `full.md`：原始需求说明，单独保留，不和状态混写。
- `HANDOFF.md`：当前交接、状态、风险、下一步。

其余仍长期有效的材料：
- `develop.md`：工程实现说明。
- `dev_plan.md`：阶段计划与门禁。
- `demo.md`：验收用例与观测指标。
- `active/`：当前仍在使用的脚本。
- `archive/`：历史 handoff/status/todo 与旧版本备份。

建议阅读顺序：`full.md -> develop.md -> dev_plan.md -> demo.md -> HANDOFF.md`
